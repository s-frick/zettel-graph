# Getting started

Point the [CLI](/components/cli.md) at any directory of OKF markdown:

```sh
npx zettel-graph ./my-notes
```

Open the printed URL, hover a node for a preview, and click for the full page.
Edit a file and the graph reloads live — the [parser](/components/parser.md)
rebuilds the graph on every change.
